# Чек-лист прогона: bot_for_legal_consultations

Как пользоваться: идти по порядку, в колонке «Факт» писать «ок» / «дефект
DEF-XXX» / «не проверено (причина)». Не перескакивать: QA-12 (общий вопрос)
идёт раньше остальных, если он падает — остальное не проверить.

Перед прогоном:
  [ ] бот запущен, БД загружена, ключ LLM живой
  [ ] логи открыты отдельным окном (нужны строки Query type / Route / hallucination)
  [ ] папка defects/ открыта для карточек
