# DEF-013 · P1 · Валидатор отклоняет основной сценарий: юридический вопрос без ответа

Проект: bot_for_legal_consultations
Дата: 2026-10-30
Источник находки: живой прогон после исправления DEF-001
Статус: **исправлено**

## Симптом

После того как общий маршрут перестал падать, три юридических вопроса из шести
вернули не ответ, а техническое сообщение:

    «❌ Не удалось сформировать корректный ответ на ваш вопрос.
       Причина: Ответ не содержит ссылок на статьи»

    L-002 «дарение что это»                       → отклонён валидатором
    L-003 «какой срок исковой давности»           → отклонён валидатором
    L-004 «можно ли расторгнуть аренду досрочно»  → отклонён валидатором

То есть система сгенерировала ответ и сама его выбросила.

## Причины (две, обе подтверждаются кодом)

1. Проверка наличия ссылок ищет только формы «статья/статьи/статью/статье»
   или «ст.» (rag_engine.py:587). Ответ, где написано «статьёй 196»,
   «статьям 454», «статей 196», считается ответом без ссылок — см. DEF-005.
2. Требование ссылки безусловно для всех «не системных» вопросов, при этом
   LLM (temperature 0.2) не обязана приводить номер статьи в каждом ответе.

## Почему это P1, а не P2

Пользователь задал нормальный юридический вопрос и не получил ничего. Причём
отказ выглядит как «система не смогла», а не «я не знаю»: это подрывает доверие
сильнее, чем честное «уточните».

## Как воспроизвести

    .venv/Scripts/python.exe tools/qa_run_reference.py
    # L-002, L-003, L-004 → outcome=validator

Диагностика причины: прогнать те же вопросы с валидатором, отключённым
(monkeypatch `AnswerValidator.validate` → True) и посмотреть, есть ли в сыром
ответе ссылка в форме «статьёй/статьям/статей». Если есть — виновата регулярка,
если нет — требование ссылки.

## Предложение

- Расширить регулярку до основы слова: `r"стать\w*\s*(\d+)"` (закрывает и DEF-005).
- Разделить отказ и ошибку: «не удалось сформировать» — это ошибка системы,
  её нельзя показывать как ответ пользователю.
- Если ссылки нет, но ответ по существу — отдавать ответ с пометкой
  «без ссылки на конкретную статью», а не выбрасывать.

## Закрытие (2026-10-30)

Три изменения в `rag_engine.py`:

1. `AnswerValidator` больше не возвращает отказ из-за отсутствия ссылки:
   он ставит пометку `no_citation` и отдаёт ответ. Внизу ответа появляется
   строка «В ответе нет ссылки на конкретную статью — если нужна точная норма,
   спросите: „что говорит статья 454“».
2. Причина отказа больше не показывается (см. DEF-014).
3. Причина, по которой ссылки «не находились», устранена (см. DEF-005) —
   на живом прогоне все три юридических вопроса получили ответ по существу.

Проверка: `tests/test_validator_rules.py` (ответ без ссылки → `is_valid=True`
и `reason_code="no_citation"`), чек-лист QA-21 → «принят с пометкой no_citation».
Эталонные кейсы: 13/13.
