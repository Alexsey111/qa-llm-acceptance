# DEF-008 · P2 · README описывает запуск тестов, которых в репозитории нет

Проект: MarketScope AI
Дата: 2026-10-30
Источник находки: сверка README с содержимым репозитория
Статус: открыт

## Симптом

README (строки 388-394) содержит раздел тестирования:

    pytest
    pytest --cov=. --cov-report=html
    pytest tests/test_scoring.py -v

Фактически в репозитории нет ни папки tests, ни одного файла test_*.py.
Проект — 38 модулей Python, в том числе скоринговый движок v4.0, который
README называет ключевой частью.

## Почему это дефект

- Человек, клонировавший проект, выполняет команду из README и получает
  «file or directory not found» — первый опыт знакомства с проектом отрицательный.
- Отсутствие тестов у скорингового движка означает, что заявленное «scoring
  engine v4.0» ничем не подтверждено: правила оценки нельзя проверить, только
  прочитать.
- В приёмке это отдельный класс: «документация обещает больше, чем есть».

## Как воспроизвести

    ls tests/                      → нет такого каталога
    grep -n "pytest" README.md     → 3 строки с командами
    find . -name "test_*.py"       → пусто

## Предложение

- Либо написать тесты на скоринг (минимально: границы весов, пустой товар,
  отсутствие данных, порядок сортировки), либо убрать раздел из README.
- В описании проекта писать «тестов нет» честнее, чем «pytest --cov»: второе
  читается как «есть покрытие».

## Замечание по методике

Первый прогон сканера дал по этому проекту ещё два «расхождения» — redis и
postgres якобы заявлены, но отсутствуют. Проверка показала: и то и другое
используется в коде (`services/cache.py`, `config.py`, `app/tasks/analysis_tasks.py`),
просто нет файлов с такими именами. Сканер искал по именам файлов и ошибся.
В карточку попало только то, что воспроизводится командами выше.
